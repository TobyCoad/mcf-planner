# Michaelmas 2026 planner

Week-by-week planner for the Oxford MSc MCF (Michaelmas 2026): modules, timetable, exams, settings.
Installable on iPad from Safari (Share > Add to Home Screen). Progress is stored on the device; use Settings > Backup to copy it out.

Deploy: push to `main` (GitHub Actions publishes to Pages). Bump `CACHE_VERSION` in `sw.js` on every deploy so installed copies show the update pill.
